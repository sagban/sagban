# Sagar Bansal

I build iPhone apps and multi-agent systems. Based in Houston, TX.

## Selected work

**[capy](https://github.com/sagban/capy)**
iPhone meal log. You describe what you ate. The agent looks up the food, converts the portion to grams, and writes one diary entry. Alexa+ and the phone share that diary through MCP.

**[FieldSight AI](https://github.com/sagban/fieldSightAI)**
Voice inspection for FPSO assets. A field assistant collects the readings. An integrity engineer computes corrosion rate and remaining life, then returns a cited verdict.

**[PermitFlow AI](https://github.com/sagban/permitflowAI)**
Permit drafts for oil and gas work orders. Four agents run hazard identification, generation, validation, and refinement.

**[ZBar barcode reader](https://github.com/sagban/Zbar-barcode-reader-python-javascript)**
Barcode and QR reader for a live webcam, laptop camera, or phone camera. Python and JavaScript.

**[react-hls-player](https://github.com/sagban/react-hls-player)**
React component for HLS live streams. `npm i @sagban/react-hls-player`

**[Waffle Park](https://sagban.github.io/WafflePark/)**
Food delivery app on MongoDB, Express, Angular, and Node.
